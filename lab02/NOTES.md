Различие Git и GitHub:
Git — это система контроля версий. Она устанавливается на компьютер разработчика и позволяет отслеживать изменения в файлах проекта, сохранять историю правок и при необходимости возвращаться к предыдущим версиям кода. 
GitHub — это веб-платформа для хранения Git-репозиториев и организации совместной работы над проектами. Она работает на основе Git, но добавляет к нему облачное хранилище и дополнительные инструменты.
раздел «Использованные команды»:
Команда git status показывает текущее состояние вашего репозитория: что изменилось с момента последнего коммита и что готово к фиксации.
Команда git diff показывает разницу между двумя состояниями вашего проекта.
Команда git diff --staged показывает разницу между индексом и последним коммитом. 
ветка в Git — это указатель (ссылка) на конкретный коммит в истории проекта.
Когда вы делаете коммит, находясь в какой-то ветке,создаётся новый коммит, и указатель этой ветки просто перемещается вперёд — на новый коммит. 
Слияние нужно, чтобы объединить изменения из одной ветки с другой. При этом сливаемая ветка сама по себе не меняется — она остаётся в прежнем состоянии, и вы можете продолжить в ней работу.
